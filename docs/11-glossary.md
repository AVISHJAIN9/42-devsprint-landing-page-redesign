# Technical Glossary: DevSprint Motion Lab

- **CSS Masking**: The technique of using an image or gradient as an alpha mask to selectively reveal or conceal underlying DOM elements.
- **OffsetLeft**: The distance in pixels from the outer left margin of an element to the inner left margin of its nearest positioned parent.
- **Parallax**: A visual effect where background layers move at a different speed than foreground layers, creating the illusion of 3D depth.
- **Resize Debouncing**: Postponing execution of a computationally expensive resize callback until user resizing stops.
